# Genova AI - 현재 구현 현황 (2026-03-23 기준)

## 요약

핵심 AI 분석 파이프라인은 완성되어 동작하며, 프론트엔드 UI는 주요 화면이 구축되어 있다. 다만 프론트엔드 일부 기능은 localStorage 기반 mock 데이터로 동작하며, 백엔드와 실제 연동이 필요한 영역이 남아있다.

**한 줄 요약**: PoC를 넘어 핵심 분석 파이프라인은 작동 가능한 수준이나, 서비스 운영 구조(프로젝트/워크스페이스, 인증/권한, 과금)는 미구현.

---

## 1. 완료된 기능 (실제 동작)

### 1-1. 영상 업로드 파이프라인
- GCS Signed URL 기반 대용량 업로드 (최대 2GB, Cloud Run 32MB 제한 우회)
- URL 기반 업로드 지원
- 업로드 확인 후 백엔드 비동기 처리 자동 시작
- 처리 상태 실시간 조회 (단계별 진행률)

### 1-2. AI 기반 분석
- Gemini 모델을 이용한 영상 전체 분석
- 영상 전체 요약 생성
- 키워드 추출
- 구간별 제목, 요약, 스크립트, 키워드 자동 생성
- 분석 결과 JSON 형태로 DB 저장 및 API 조회

### 1-3. 자막과 구간 정보
- 구간별 시작/종료 시간, 제목, 요약, 분류(도입/본문/결론) 저장
- 결과 화면에서 요약/스크립트/분할 탭 구조로 열람

### 1-4. 영상 분할 다운로드
- FFmpeg 기반 구간별 영상 클립 분할
- 개별/일괄 다운로드
- 썸네일 이미지 포함 옵션

### 1-5. 다국어 번역
- 영상 전체 + 구간별 번역 구조
- 요청 언어 기준 on-demand 번역 (ko, en, ja, zh)
- 번역 결과 캐싱 및 재사용

### 1-6. 운영 기반
- Health Check API (DB, Redis, GCP, 디스크 점검)
- 모니터링 API
- Redis 기반 처리 상태 실시간 추적
- 에러 모니터링 및 복구 시스템

### 1-7. 프론트엔드 화면
- 워크스페이스 진입 구조
- 새 프로젝트 / 업로드 UI (다단계: 업로드 → 설정 → 분석 → 완료)
- 결과 상세 화면 (요약/스크립트/분할 탭)
- Video.js 기반 영상 플레이어 (타임라인 마커, 재생속도 조절)
- 관리 페이지 (회원 관리, 구독 정보)
- 설정/내 정보 화면
- 공통 컴포넌트 (Button, Modal, Input, Select, Toggle, VideoPlayer)

## 2. 부분 구현 (UI 존재, 백엔드 미연동)

다음 항목들은 **프론트엔드 UI가 구축되어 있으나 localStorage mock 데이터 기반**으로 동작하며, 실제 백엔드 API 연동이 필요하다.

| 기능 | UI 상태 | 백엔드 상태 | 비고 |
|------|---------|------------|------|
| 워크스페이스 목록 | mock 완료 | 미구현 | localStorage 기반 |
| 프로젝트/작업 관리 | mock 완료 | 미구현 | 사용자→프로젝트→영상→분석 구조 필요 |
| 분석 버전 관리 (A/B) | UI 초안 | 미구현 | 같은 영상 다른 설정 재분석 |
| 프리셋 저장/재사용 | UI 초안 | 미구현 | 프롬프트 프리셋 영속 저장 필요 |
| 분석 설정 적용 | UI 완료 | 미연동 | 프리셋 선택이 실제 Gemini 호출에 미반영 |
| 회원 관리 | UI 완료 | 미구현 | 기관/사용자/권한 구조 필요 |
| 구독/토큰 관리 | UI 초안 | 미구현 | 기관 공용 토큰 풀 정책 |

## 3. 미구현

| 기능 | 설명 |
|------|------|
| 인증/권한 체계 | 현재 개발 편의 중심, 기관/관리자/사용자 역할 분리 필요 |
| 결과 편집/저장 | 생성된 요약/스크립트를 사용자가 수정하고 저장 |

| 데이터 보관 정책 | 원본 보관 기간, 다운로드 URL 만료, 삭제 요청 처리 |
| 작업 큐 관리 | 대용량/동시 처리 시 큐 시스템 |
| 에러 알림 | 운영 대시보드, 실패 알림 |
