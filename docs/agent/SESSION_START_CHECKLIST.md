# Session Start Checklist

## 시작 전 확인

1. `AGENTS.md`를 읽는다.
2. `docs/progress/`에서 현재 진행 중인 작업과 점유 경로를 확인한다.
3. `docs/plan/INDEX.md`에서 현재 우선순위를 확인한다.
4. 역할 호출이 있으면 대응되는 `docs/agent/roles/` 문서를 읽는다.
5. 새 작업이면 `docs/progress/`에 작업 문서를 만든다.

## 종료 전 확인

1. `docs/progress/`의 현재 상태와 최근 업데이트를 정리한다.
2. 완료된 작업은 `docs/done/`으로 옮긴다.
3. 큰 그림이 바뀌었으면 `docs/plan/INDEX.md`를 갱신한다.
