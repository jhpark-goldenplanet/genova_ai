## 2) 기능 범위 정리
### 2-1. 필요한 기능 (To Keep / To Add)
- [ ] 작업 생성 진입점: `새 작업`
- [ ] 각 작업은 `원본영상 1개`를 필수로 가짐
- [ ] 원본영상 등록 후 동일 작업 내에서 다중 분석 버전 생성 가능
- [ ] 작업목록 화면은 스크롤 기반 리스트/카드 형태로 제공
- [ ] 작업 선택 시 1차 요약 패널 제공 + `상세 보기` 버튼으로 상세 페이지 진입
- [ ] 상세 화면에서 `프롬프트 수정/스크립트 수정/수동 분할` 후 `재생성(Generate)` 지원
- [ ] 재생성은 기존 결과 덮어쓰기보다 `새 분석 버전` 생성 중심으로 설계
- [ ] 작업공간(Workspace/Space) 개념 도입
- [ ] 사용자별 분석 작업 목록 화면 (내가 분석한 영상 리스트)
- [ ] 작업 상세 진입 시 통합 보기 제공: 원본영상 / 스크립트 / 분할점 / 요약
- [ ] 단건 분석 후 결과 휘발 UX 제거 (재방문/재열람 가능 구조)
- [ ] 작업공간에 `원본영상` + `분할 결과물` 모두 보관
- [ ] 원본영상 1개에 대해 다중 분석 버전(A/B/...) 생성 및 비교 지원
- [ ] 분석 버전별 설정값(프롬프트, 분할 기준, 옵션) 이력 저장
- [ ] 프롬프트 프리셋 저장/재사용 기능
- [ ] 신규 단계 추가: `영상 업로드 -> 분석 설정 -> 분석 시작`
- [ ] 기본 분석 모드: `AI 자동 분석` (기본값 확정)
- [ ] 모드 선택 UI: `AI 자동 분석` / `커스텀 분석`
- [ ] 커스텀 모드 UI(상세 항목은 추후 확정): 프롬프트, 분할 기준 등 설정 영역
- [ ] 업로드 직후 메타데이터 노출 UI(항목 상세는 추후 확정)
- [ ] 상단/사이드 메뉴의 `회원 관리`를 `관리` 페이지로 통합 개편
- [ ] `관리` 페이지 내 탭/섹션: `회원 관리` + `구독 정보`
- [ ] 구독 모델: 개인별 토큰이 아닌 `기관(농정원) 공용 토큰 풀`
- [ ] 구독 정보 표시 항목: `플랜`, `토큰 갱신일`, `현재 남은 토큰`, `최초 시작일`
- [ ] 플랜 단계 임시안: `Basic` / `Plus` / `Pro` (명칭 추후 확정)
- [ ] 플랜 차등 요소: `월 토큰량`, `플랜 내 사용자 수`
- [ ] 결제 자동화 없이 `플랜 변경 신청 -> 운영자 수동 반영` 프로세스
- [ ] 사이드바 메뉴 개편: `워크스페이스`, `관리`, `공지사항`
- [ ] 사이드바 하단: `내 정보` + `설정(톱니바퀴)` 진입
- [ ] 설정 화면 MVP: 닉네임 수정
- [ ] (논의 필요) 시연에서 반드시 보여줄 핵심 사용자 흐름
- [ ] (논의 필요) 업로드/요약/스크립트/분할 중 필수 화면
- [ ] (논의 필요) 회의에서 의사결정에 필요한 상태 화면(로딩/에러/빈 상태)

## 4) 결정 로그
### 2026-03-11
- `개발환경실행/개발환경종료` 명령으로 로컬 개발환경 원클릭 실행/종료 구성
- `backend/deploy-local.sh`를 `uv` 기반으로 정합화 (`requirements.txt` 의존 제거)
- 기획 방식은 "대화 기반 신속 합의 + 문서 기록"으로 진행
- 1차 기능안 확정: 업로드 즉시 분석이 아닌 `업로드 -> 분석 설정 -> 사용자 시작` 구조로 전환
- 분석 기본모드는 `AI 자동 분석`으로 확정
- 메타데이터 노출 항목/커스텀 상세 설정값은 대기 (큰 기획 확정 후 상세화)
- 2차 기능안 추가: 사용자별 작업공간 기반으로 과거 분석 작업 재열람 구조 도입
- 상세 화면은 `원본영상/스크립트/분할점/요약` 통합 보기 방향으로 검토
- 3차 기능안 추가: 원본 1개에 대해 분석 버전(A/B) 비교 가능 구조로 확장
- 버전별 프롬프트/설정 이력 저장 및 프롬프트 프리셋 재사용 요구사항 추가
- 4차 기능안 추가: `회원 관리`를 `관리`로 확장하고 `회원 관리/구독 정보`를 통합 제공
- 토큰 정책은 사용자별이 아닌 기관 공용 토큰 풀 방식으로 확정
- 구독 플랜은 임시로 `Basic/Plus/Pro` 3단계, 결제는 외부(수동 반영) 프로세스로 운영
- 메뉴 구조 개편안 합의: `워크스페이스/관리/공지사항` + 하단 `내 정보/설정`
- `새 작업`에 영상 미등록 시 기존 `영상 업로드` UI 리소스를 그대로 재사용
- 작업 선택 UX: 목록에서 간단 요약 확인 후 `상세 보기`로 이동
- 상세에서 편집/재생성은 버전 누적 방식(A/B) 중심으로 설계

## 6) UI 정보구조 초안 v1
### 엔티티
- `작업`: 사용자 단위 컨테이너 (원본영상 1개 필수)
- `분석 버전`: 작업 하위 결과물(A/B/...) (프롬프트/옵션/결과 별도 저장)

### 화면 구조
- `작업목록`
  - 스크롤형 카드 리스트
  - 워크스페이스 진입 시 기본 랜딩 화면
  - 카드 클릭 시 `작업 상세` 진입
  - 상단 `새 작업` 버튼
  - 카드 선택 시 간단 `작업 요약` 패널 표시
  - 요약 패널 내 `상세 보기` 버튼 제공
  - 각 작업 클릭 시: `원본 영상` + `하위 분석 작업 목록(완료본)` 표시
- `작업 상세`
  - 원본영상 영역
  - 분석 버전 영역
  - 버전이 없으면 빈 상태: `작업 내용이 없습니다` + `새 분석 시작`
  - 버전이 있으면 하위 컨텐츠 리스트/탭 표시
  - 탭 구조(초안): 개요 / 요약 / 스크립트 / 분할 / 설정·재생성
  - 상단 `작업목록으로 돌아가기` 버튼 제공

### 빈 상태 UX
- `새 작업` 생성 후 원본영상이 없으면 기존 `영상 업로드` 화면 리소스를 노출
- 기존 업로드 컴포넌트/문구/인터랙션은 최대한 재사용
- 기존 업로드 페이지의 배경 이미지 스타일 유지

## 9) 워크스페이스 흐름 요약 v1
1. 사이드바 `워크스페이스` 클릭 -> `작업목록` 진입

5. 하위 작업 클릭 시 작업 요약 확인
6. `상세 보기` 클릭 시 작업 상세 페이지 이동
7. 상세 페이지 상단에서 `작업목록으로 돌아가기` 가능
