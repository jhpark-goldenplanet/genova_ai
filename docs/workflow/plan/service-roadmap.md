# Service Roadmap

## 목적

- Genova AI의 현재 서비스 방향과 기능 단위 로드맵을 관리한다.
- 기획 결정은 이 문서에 누적하고, 세션별 작업 상황은 `docs/workflow/progress/`, 완료 상세는 `docs/workflow/done/`으로 분리한다.

## 현재 작업 원칙

- 단계 1: 사용자와 기능 범위 합의
- 단계 2: 합의된 범위 기준으로 UI 먼저 구현
- 단계 3: 회의 피드백 반영 후 기획 확정
- 단계 4: 확정 스펙 기준으로 백엔드 구현 병행

## 로드맵 상태

### P1. 워크스페이스 기반 분석 흐름

- 상태: 부분 구현
- 목표: 업로드 이후 결과가 휘발되지 않고 작업 단위로 재방문 가능한 구조 확립

미구현
- 분석 버전 비교 기능의 실제 제품 완성
- 버전별 설정값과 프롬프트 이력의 서버 영속 저장
- 작업/분석 버전 정보구조의 백엔드 모델과 API 연동

### P1. 분석 시작 흐름 재정의

- 상태: 부분 구현
- 목표: 업로드 즉시 분석 대신 설정 기반 분석 시작 흐름으로 전환

미구현
- 분석 설정값의 백엔드 저장과 실제 분석 파이프라인 연동
- 업로드 이후 작업/분석 시작 흐름의 서버 기준 상태 관리

### P1. 관리 정보구조 개편

- 상태: 부분 구현
- 목표: 회원 관리와 구독 정보를 `관리` 영역으로 통합

미구현
- 기관 공용 토큰 풀의 실제 데이터 구조와 정책 구현
- 플랜 변경 신청 후 운영자 수동 반영 프로세스 구현
- 회원 관리/구독 관리의 실데이터 연동

## 결정 로그

### 2026-03-11

- 업로드 즉시 분석이 아닌 `업로드 -> 분석 설정 -> 사용자 시작` 구조로 전환
- 분석 기본모드는 `AI 자동 분석`으로 확정
- 사용자별 작업공간 기반으로 과거 분석 작업 재열람 구조 도입
- 상세 화면은 `원본영상/스크립트/분할점/요약` 통합 보기 방향으로 검토
- 원본 1개에 대해 분석 버전(A/B) 비교 가능 구조로 확장
- 토큰 정책은 사용자별이 아닌 기관 공용 토큰 풀 방식으로 확정
- 구독 플랜은 임시로 `Basic/Plus/Pro` 3단계, 결제는 수동 반영 프로세스로 운영
- 메뉴 구조는 `워크스페이스/관리/공지사항` + 하단 `내 정보/설정` 방향으로 합의
