# Service Roadmap

## 목적

- Genova AI의 현재 서비스 방향과 기능 단위 로드맵을 관리한다.
- 기획 결정은 이 문서에 누적하고, 세션별 작업 상황은 `docs/progress/`, 완료 상세는 `docs/done/`으로 분리한다.

## 현재 작업 원칙

- 단계 1: 사용자와 기능 범위 합의
- 단계 2: 합의된 범위 기준으로 UI 먼저 구현
- 단계 3: 회의 피드백 반영 후 기획 확정
- 단계 4: 확정 스펙 기준으로 백엔드 구현 병행

## 로드맵 상태

### P1. 워크스페이스 기반 분석 흐름

- 상태: 부분 구현
- 목표: 업로드 이후 결과가 휘발되지 않고 작업 단위로 재방문 가능한 구조 확립

주요 항목
- 완료
- `새 작업` 진입점 제공
- 작업목록 화면을 스크롤 기반 리스트 또는 카드 형태로 제공
- 작업 선택 시 요약 정보와 상세 진입 구조 제공
- 작업 상세에서 원본영상, 스크립트, 분할점, 요약 탭 구조 제공

- 부분 구현
- 작업당 `원본영상 1개` 구조를 프론트 목업 기준으로 반영
- 분석 버전(A/B/...) 생성 흐름을 프론트 임시 저장 기준으로 반영
- 프롬프트 프리셋 저장과 재사용 UI를 프론트 임시 저장 기준으로 반영

- 미구현
- 분석 버전 비교 기능의 실제 제품 완성
- 버전별 설정값과 프롬프트 이력의 서버 영속 저장
- 작업/분석 버전 정보구조의 백엔드 모델과 API 연동

### P1. 분석 시작 흐름 재정의

- 상태: 부분 구현
- 목표: 업로드 즉시 분석 대신 설정 기반 분석 시작 흐름으로 전환

주요 항목
- 완료
- 신규 단계: `영상 업로드 -> 분석 설정 -> 분석 시작` 화면 흐름 반영
- 기본 분석 모드: `AI 자동 분석`
- 모드 선택 UI: `AI 자동 분석` / `커스텀 분석`
- 커스텀 모드 설정 영역 제공

- 부분 구현
- 업로드 직후 메타데이터 노출 UI 일부 반영
- 설정 저장과 재생성 흐름을 프론트 임시 상태 기준으로 반영

- 미구현
- 분석 설정값의 백엔드 저장과 실제 분석 파이프라인 연동
- 업로드 이후 작업/분석 시작 흐름의 서버 기준 상태 관리

### P1. 관리 정보구조 개편

- 상태: 부분 구현
- 목표: 회원 관리와 구독 정보를 `관리` 영역으로 통합

주요 항목
- 완료
- 사이드 메뉴의 `관리` 진입 구조 반영
- `관리` 내 `회원 관리` + `구독 정보` 화면 분리 반영
- 구독 정보 표시 UI 초안 반영

- 부분 구현
- 기관 공용 토큰 풀 정책을 문구와 목업 데이터에 반영
- 플랜 변경 신청 버튼과 안내 문구 반영

- 미구현
- 기관 공용 토큰 풀의 실제 데이터 구조와 정책 구현
- 플랜 변경 신청 후 운영자 수동 반영 프로세스 구현
- 회원 관리/구독 관리의 실데이터 연동

### P2. 내 정보 및 설정

- 상태: 완료
- 목표: 사용자 기본 설정 진입점 정리

주요 항목
- 완료
- 사이드바 하단 `내 정보` + `설정` 진입
- 설정 MVP: 닉네임 수정

### P2. 시연용 상태 화면 정리

- 상태: 미구현
- 목표: 회의 시연에서 필요한 상태를 빠르게 전달할 수 있는 화면 준비

주요 항목
- 미구현
- 로딩 상태 정리
- 에러 상태 정리
- 빈 상태 정리
- 이번 회의에서 반드시 보여줄 핵심 화면 3~5개 확정

## 내일 오전 시연 대응

### P0. 시연용 UI 정리

- 상태: 진행 예정
- 목표: 내일 오전 시연에서 보여줄 핵심 사용자 흐름의 완성도와 일관성을 우선 확보

주요 항목
- 시연 대상 화면 3~5개 확정
- 시연 흐름 기준으로 문구, 버튼 라벨, 빈 상태, 정렬 상태 정리
- 목업 데이터와 실제 화면 상태의 불일치 최소화
- 작업목록, 새 작업, 작업 상세, 관리 화면의 시각적 일관성 점검
- 시연 중 노출되면 안 되는 미완성 요소 식별 및 임시 가드 처리

## 결정 로그

### 2026-03-11

- 기획 방식은 대화 기반 신속 합의 + 문서 기록으로 진행
- 회의 시연을 위해 UI 선구축 후 백엔드 구현을 병행하는 방향으로 정리
- 업로드 즉시 분석이 아닌 `업로드 -> 분석 설정 -> 사용자 시작` 구조로 전환
- 분석 기본모드는 `AI 자동 분석`으로 확정
- 사용자별 작업공간 기반으로 과거 분석 작업 재열람 구조 도입
- 상세 화면은 `원본영상/스크립트/분할점/요약` 통합 보기 방향으로 검토
- 원본 1개에 대해 분석 버전(A/B) 비교 가능 구조로 확장
- 버전별 프롬프트와 설정 이력 저장, 프리셋 재사용 요구사항 추가
- `회원 관리`를 `관리`로 확장하고 `회원 관리/구독 정보`를 통합 제공
- 토큰 정책은 사용자별이 아닌 기관 공용 토큰 풀 방식으로 확정
- 구독 플랜은 임시로 `Basic/Plus/Pro` 3단계, 결제는 수동 반영 프로세스로 운영
- 메뉴 구조는 `워크스페이스/관리/공지사항` + 하단 `내 정보/설정` 방향으로 합의
- `새 작업`에 영상 미등록 시 기존 업로드 UI 리소스를 재사용
- 작업 선택 UX는 목록에서 간단 요약 확인 후 `상세 보기`로 이동
- 상세에서 편집과 재생성은 버전 누적 방식 중심으로 설계

## 다음 논의 항목

- 각 화면에서 보여줄 핵심 액션 1개씩
- 이번 회의에서 제외할 기능 목록
