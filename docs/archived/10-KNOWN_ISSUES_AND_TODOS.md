## 알려진 이슈

### 1. YouTube 다운로드 제한

**문제:**
- YouTube의 봇 감지로 인해 일부 비디오 다운로드 실패
- 쿠키 인증이 필요한 경우 있음

**임시 해결책:**
- YouTube 쿠키 파일 업로드 기능 사용
- 일반 URL 업로드 권장

**관련 파일:**
- `ax-agriedu-back-v3/app/services/youtube_download_service.py`
- `ax-agriedu-back-v3/app/api/v1/youtube_cookies.py`

---

### 2. 긴 비디오 처리 시간

**문제:**
- 30분 이상 비디오는 처리에 15분 이상 소요
- Cloud Run 타임아웃(900초)에 근접

**임시 해결책:**
- 상태 폴링으로 비동기 처리
- 사용자에게 처리 시간 안내

**향후 계획:**
- Cloud Tasks를 통한 장시간 작업 분리
- 비디오 청크 처리 구현

---

### 3. 4K 비디오 메모리 사용량

**문제:**
- 4K 비디오 처리 시 메모리 사용량 급증
- OOMKilled 발생 가능

**현재 해결책:**
- 4K 자동 감지 후 1080p 다운샘플링

**관련 파일:**
- `ax-agriedu-back-v3/app/services/video_processing_pipeline.py`

---

### 4. Speech-to-Text 정확도

**문제:**
- 배경 소음이 많은 비디오에서 음성 인식 정확도 저하
- 전문 용어 인식 한계

**임시 해결책:**
- 사용자가 스크립트 수동 편집 가능

---

### 5. 동시 처리 제한

**문제:**
- 인스턴스당 동시 요청 10개 제한
- 대량 업로드 시 지연 발생

**현재 설정:**
- 최대 인스턴스: 10
- 인스턴스당 동시성: 10
- 총 동시 처리: 100

## 성능 개선 포인트

### 백엔드

1. **데이터베이스 쿼리 최적화**
   - N+1 쿼리 제거
   - 인덱스 최적화

2. **캐싱 강화**
   - 분석 결과 캐싱
   - Signed URL 캐싱

3. **비동기 처리 개선**
   - Background Tasks 활용
   - Queue 시스템 도입

### 프론트엔드

1. **번들 크기 최적화**
   - 코드 스플리팅
   - 트리 쉐이킹

2. **이미지 최적화**
   - Next.js Image 컴포넌트 활용
   - WebP 포맷 지원

3. **렌더링 최적화**
   - React.memo 활용
   - useMemo/useCallback 최적화
